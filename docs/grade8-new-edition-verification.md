# 北师大新版八上核验与入库记录

日期：2026-10-25。本次目标为通常标作“北师大版（2024）”的新版八年级上册，不覆盖原八上405词候选包。

## 版本证据

- **封面已核对**：出版社自身在线教材封面为首钢滑雪大跳台，左上角原文“国家教材委员会专家委员会审核通过 2024”。应区分审核年份与出版、印刷年份，不能据此写成“2024年第一版”。[本地封面证据](evidence/grade8-2024/cover.jpg)。
- 出版社：[北京师范大学出版社同步电子教材](https://www.100875.com.cn/show/resourceDetail_eBookAndTeacher.html?resId=bcaea735884649bdad5d81eb2b6f652b&type=SYN&contributeId=dabd044b4c5146b79e544fe2d3e31ce9&tp=Ebook)。公开资源类型为“北师大新版 > 八年级上册”。
- **版权页未完成核验**：上述教材的“扉页等”公开接口 functionPageList 返回空数组；在线正文图从Contents开始，末尾为不规则动词，未获得版权页原图。因此不确认具体版次年月、印次，也不把第三方列出的“2025年6月第1版”当作结论。
- **ISBN为出版社书目交叉证据**：978-7-303-30739-5，[出版社2025年秋价格核定表](https://www.bnupg.com/docs/2025-10/5d9722d013864e0e87a26f45d3e04b77.pdf)明确列“义务教育教科书·英语 八年级上册（新）”。尚未与本册版权页原图逐字段确认。
- 网页显示“2024审核新版（版权页待核）”，封面、单元和释义为已对照，版权页和具体版次为待核。

处理规则：

- DOCX按段落读取，跨段释义合并到末尾教材页码，避免漏掉bully、upset、tear等后续释义或第二读音。
- 页码135–140是六单元听力稿，与词汇页的单元分组逐一对应，分别归Unit 1–6；不是第七单元。其他主词按已核目录页码归属。
- 保留词组、音标、课内释义、原书星号和教材页码；英文中移除星号，便于TTS读音。星号和页码在CSV附加列及审校JSON保留，当前学习界面导入主字段。
- 单元内按教材引用页码排序，同页按英文排序；听力词仍在所属单元。顺序不是原词汇页逐行顺序。
- 本轮涵盖六单元**主词表**，不含单独列出的Proper Nouns、Countries and Places、Names附录。主词表内的Iron Hammer、BCE等仍保留。
- 发音继续使用系统英语TTS，不宣称教材原声。没有新增自动发音评分或听写功能。

## 新旧版本隔离

新目录ID为 `bnu-grade8-upper-2024`，独立标题及版次；旧目录ID `bnu-grade8-upper` 与原CSV哈希未改。两版分别导入，不归档、不删除、不迁移旧版词和评分。

已经在用户当前浏览器页面完成新版460词的确认导入，刷新后仍显示460词和六个单元。导入前该浏览器档案无已导入教材。旧版405词仍在分册目录中；测试另构造“旧版已学习→新版重复导入”场景，验证原词、卡片和评分全部保留。未在用户档案中生成任何学习评分。
